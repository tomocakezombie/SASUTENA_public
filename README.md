# SASUTENA

**余剰食品や未使用品を、必要とする人へ届けるマッチングプラットフォーム**

SASUTENA（サステナ）は、生産者が抱える余剰食品・未使用品を消費者とマッチングし、食品ロスの削減と資源の有効活用を目指す Web アプリケーションです。山梨大学の学生チーム「Sdpl-2025」によるチーム開発プロダクトとして制作されました。

## 主な機能

### ユーザー向け
- **ロールベースのアカウント管理**: 生産者 / 消費者 / 管理者の 3 ロール
- **メール認証付き新規登録**: 6 桁の認証コードによる本人確認と管理者承認フロー
- **商品の出品・申請**: 生産者による出品、消費者による申請（申請中 / 承認 / 拒否 / キャンセル）
- **商品コメント**: `@ユーザー名` によるメンション機能付き
- **ダイレクトメッセージ**: 商品に紐づく 1 対 1 のメッセージ機能（未読バッジ・編集・削除対応）
- **ユーザー評価**: 取引完了後に消費者が生産者を評価
- **プロフィール**: アイコン画像・ニックネーム・公開設定のカスタマイズ

### 管理者向け
- 出品の承認 / 却下（自動公開 / 手動承認の切り替え可能）
- 新規登録申請の承認
- タグマスタの管理
- 締め切り間近通知の表示設定（文言・色・発動日数）
- メッセージ・ユーザー活動の監視

## セットアップ

### 1. 依存パッケージのインストール

```bash
pip install "Django==4.2.11" Pillow
```

### 2. データベースの初期化

```bash
python3 manage.py migrate
```

### 3. 初期データの投入（タグマスタ）

```bash
python3 manage.py loaddata product/fixtures/tagtype_initial.json
```

### 4. 管理者ユーザーの作成

```bash
python3 manage.py createsuperuser
```

### 5. 開発サーバーの起動

```bash
python3 manage.py runserver
```

ブラウザで `http://127.0.0.1:8000/` にアクセスしてください。

## 本番運用にあたっての注意

本リポジトリはチーム開発の学習用途を想定しており、本番環境での利用には以下の対応が必要です。

- `sasutenaproject/settings.py` の `SECRET_KEY`・メール認証情報は環境変数などで外部化してください
- `DEBUG = False` への切り替えと `ALLOWED_HOSTS` の適切な設定を行ってください
- SQLite3 から PostgreSQL などの本番向け DB への移行を検討してください
- メディアファイル（アップロード画像）の配信方法を本番環境に合わせて構成してください
